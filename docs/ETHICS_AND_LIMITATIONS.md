# Этика, приватность и ограничения

## Приватность
- Координаты пользователя используются только в рамках одного запроса: не пишутся в файлы, базы и логи; по умолчанию — ручной ввод/выбор ориентира, без GPS.
- Во внешние сервисы (только если пользователь включил): OSRM получает пары координат для расчёта пешего маршрута; Gemini получает текст запроса и данные найденных мест, **без координат пользователя**. Обе опции выключены по умолчанию.
- Ключи API — только в `.env`, который не попадает в Git.

## Борьба с недостоверной информацией
- Рекомендуются только записи из базы; перед выдачей они сверяются с базой (название, координаты, расчёты).
- Нет часов работы → «неизвестно»; не разобрали формат → «неизвестно»; закрыто по данным → исключаем.
- Розетки, тишина, доступность для коляски, возрастная пригодность — показываем только при наличии тегов; иначе «не подтверждено».
- События и выставки: данных нет — система не утверждает, что что-то проходит сейчас.
- Каждый факт помечен источником; у каждой карточки есть ссылка на запись OSM и дата получения; данные старше 45 дней помечаются как возможно устаревшие.

## Безопасность пользователей
- Для «до вылета» система закладывает запас на дорогу и регистрацию (по умолчанию 90 мин) и при нехватке времени советует остаться в аэропорту.
- Ночью приоритет у мест с подтверждённо открытыми часами; неизвестные часы штрафуются.
- Система не даёт медицинских/юридических советов и не заменяет карты и официальные расписания.

## Известные ограничения (честно)
1. **Полнота OSM.** Описаний мало, часы работы есть не у всех, рейтингов и цен нет. Качество зависит от разметки OSM в Астане.
2. **Расстояния** по умолчанию — оценка (прямая × 1.3). Реальный маршрут — только с включённым OSRM и интернетом.
3. **Нет данных реального времени:** афиши, загруженность, погода, закрытия на ремонт.
4. **Часы работы:** разбираются простые форматы OSM; праздники (PH), сложные правила → «неизвестно».
5. **Языки:** ru и en полностью; kk — только по ключевым словам, ответ на русском. Латиница на другом языке (например, французский) распознаётся как английский, но ключевые слова не поймёт.
6. **Поиск лексический**, а не нейросетевой: редкие синонимы и смысловые формулировки без ключевых слов могут не сработать.
7. **Координаты ориентиров приблизительные** — проверьте на карте.
8. **Бюджет** — эвристика по категории и тегу `fee`, цен нет.
9. **Группа:** вместимость и бронирование не проверяются.
10. Публичные API имеют лимиты (fair use); при сбое сбор можно повторить.
