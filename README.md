# Astana Walk AI — команда Unsurprised

ИИ-помощник по прогулкам в Астане. Пользователь пишет запрос естественным языком, система находит **реальные места из OpenStreetMap**,
учитывает расстояние, время, часы работы и ограничения и выдаёт 1–3 места или мини-маршрут с объяснением «почему» и пометкой источника каждого факта.

**Что реально работает:** автоматический сбор POI → очистка → гео-фильтр → текстовый поиск (TF-IDF) → ранжирование → расчёт времени → мини-маршрут → проверка результата → интерфейс Streamlit.
**Чего нет (и мы это честно говорим):** данных в реальном времени (афиши, загруженность), цен, рейтингов; расстояния по умолчанию — оценка по прямой × 1.3.

## Быстрый старт (Windows, PowerShell, без активации venv)

Все команды — из папки `astana-walk-ai`.

```powershell
# 1. Установить библиотеки (один раз)
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

# 2. Собрать данные из OpenStreetMap (5–10 минут, можно запускать повторно)
.\.venv\Scripts\python.exe collect_poi.py

# 3. Очистить данные
.\.venv\Scripts\python.exe process_data.py

# 4. Автотесты
.\.venv\Scripts\python.exe -m pytest -q

# 5. Прогон сценариев на реальных данных -> docs/TEST_RESULTS.md
.\.venv\Scripts\python.exe run_scenarios.py

# 6. Запуск интерфейса (откроется браузер; если спросит e-mail — нажмите Enter)
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Если сбор данных прервался — просто запустите шаг 2 ещё раз: готовые группы берутся из кэша `data/raw/`. Скачать заново: `collect_poi.py --refresh`.

## Необязательно: языковая модель
Скопируйте `.env.example` в `.env` и вставьте бесплатный ключ Google AI Studio в `GEMINI_API_KEY`. Тогда в интерфейсе станет доступна галочка «Генерация текста ИИ».
Любой ответ модели проверяется (числа, названия, утверждения про розетки/события/открытость); при сбое остаётся режим шаблонов. Ключ не коммитим (`.env` в `.gitignore`).

## Структура
| Файл | Назначение |
|---|---|
| `collect_poi.py` | автосбор POI из OSM (Overpass API), повторы, кэш, дедупликация |
| `process_data.py` | очистка, категории, проверка координат, документы для поиска |
| `query_parser.py` | язык, интересы, время, группа, ограничения из текста запроса |
| `retrieval.py` | индекс TF-IDF (слова + 3-граммы символов) |
| `geo.py`, `hours.py` | расстояния/радиус, разбор часов работы OSM |
| `route_planner.py` | пешие расстояния (оценка или OSRM), мини-маршрут |
| `recommender.py` | ядро RAG: фильтры, ранжирование, объяснения, проверка |
| `llm.py` | необязательная генерация текста + верификатор |
| `app.py` | интерфейс Streamlit |
| `run_scenarios.py`, `tests/` | сценарии на реальных данных и автотесты |
| `docs/` | архитектура, этика и ограничения, презентация, ответы жюри |
